Wie ben ik?

Ik ben Dylan Vanbeneden, een student programmeren (graduaat) aan de hoge school Thomas More in Turnhout.



Waar ben ik goed in?

Ik ben een doorzettende werker, die zeer gemotiveerd is om zelfstandig bij te leren. Aanvullend, kan ik efficiënt en gecoördineerd samenwerken in een team.
Ten slotte is structuur zeer belangrijk voor mij; ik verlies niet snel essentiële documenten, ik vind alles makkelijk terug.


Waar ben ik slecht in?

Mijn grootste werkpunt is op tijd aan taken beginnen; vaak onderschat ik hoe veel tijd een project kost, wat tot tijdnood kan lijden.
Desondanks, werk ik mijn projecten nog steeds af; ik heb het nodige doorzettingsvermogen om door te werken aan een project tot ze af is.
